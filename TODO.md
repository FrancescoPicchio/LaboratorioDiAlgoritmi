## Heap

Heap può essere min o max.
    **Proprietà fondamentale**: ```Nodo A < Parent(Nodo A)``` (in max heap)
Quindi il max (o min) sta sempre alla radice.

### Struttura heap usando Array Array

- Radice dell'albero: A(i)
- Padre di A(i) -> A(i//2)
- Figlio sx di A(i) -> A(2i)
- Figlio dx di A(i) -> A(2i + 1)
